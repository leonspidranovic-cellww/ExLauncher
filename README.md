# ExLauncher

A modern, open-source Minecraft launcher built with Java 17 + JavaFX 21.

## Features

- 🎨 Modern rounded UI with animated background
- 📦 Browse and install mods from **Modrinth** and **CurseForge**
- ☕ Auto-download Java (Adoptium Temurin 8/16/17/21)
- 🔒 Isolated profiles (sandboxed `.minecraft` folders)
- 🌐 Server list with live pings
- 🎛️ QID — Quick Interface Designer (drag-and-drop layout editor)
- 🚀 Optimized JVM arguments (ZGC / Shenandoah / G1GC)
- 🔍 Smart crash analyzer

## Status

Early development. Core launcher works, mod integrations in progress.

## Tech Stack

- Java 17
- JavaFX 21
- Maven
- Gson
